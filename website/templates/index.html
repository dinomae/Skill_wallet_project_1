Methodology & Architecture

Technical Pipeline Overview

1. Data Ingestion & SQL

Loaded 200,000 records across 39 attributes into database. Validated constraints, normalized categorical aliases, and verified integrity.

2. Tableau Hyper Extract

Compiled high-speed Tableau Data Extract (.hyper) rendering 100% of data with 0 calculated fields to guarantee maximum rendering throughput.

3. Web UI Integration

Wrapped Tableau Public embed endpoints within a modern Python Flask micro-service with responsive styling and RESTful stats API.
